The script implements the following logic:
1. **Initializes Composio** with the `OpenAIProvider`.
2. **Creates a session** for the user `zealt-user01` with `multi_account` mode enabled.
3. **Authorizes two Slack accounts** with the aliases `work-slack` and `personal-slack`.
4. **Fetches Slack tools** scoped to the session.
5. **Initializes an OpenAI agent** and prompts it to send messages to the `#general` channel using the respective accounts by their aliases.
6. **Handles tool calls** automatically through the Composio session.

You can find the script at `/home/user/multi-account-task/multi_slack.py`.

```python
import os
from openai import OpenAI
from composio import Composio
from composio_openai import OpenAIProvider

# Initialize OpenAI SDK
openai_client = OpenAI()

# 1. Initialize Composio with OpenAIProvider
composio = Composio(provider=OpenAIProvider())

# 2. Create a session for the user 'zealt-user01' with multi_account mode enabled
session = composio.create(user_id="zealt-user01", multi_account={"enable": True})

# 3. Ensure both Slack connections exist with their respective aliases
print("Ensuring Slack accounts are authorized with aliases...")
session.authorize("slack", alias="work-slack")
session.authorize("slack", alias="personal-slack")

# 4. Initialize an OpenAI agent with the session tools
tools = session.tools.get(toolkits=["slack"])

# 5. Prompt the agent to send messages using the specific accounts
prompt = (
    "Send 'Hello from Work!' to #general using the 'work-slack' account, "
    "and 'Hello from Personal!' to #general using the 'personal-slack' account."
)

print(f"Agent Prompt: {prompt}")

# Execute the AI agent
response = openai_client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system", 
            "content": "You are a helpful assistant that can manage multiple Slack accounts. "
                       "Use the provided tools to send messages, and always use the correct "
                       "account alias as specified in the request."
        },
        {"role": "user", "content": prompt}
    ],
    tools=tools,
    tool_choice="auto"
)

# 6. Handle the tool calls generated by the AI agent
print("Processing agent response and executing tool calls...")
result = session.handle_tool_calls(response)

print("Task completed.")
print(f"Execution Result: {result}")
```   
