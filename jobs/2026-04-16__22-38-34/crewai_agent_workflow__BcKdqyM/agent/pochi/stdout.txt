### What the script does

| Step | Code | Purpose |
|---|---|---|
| 1 | `Composio(provider=CrewAIProvider())` | Initialises Composio with the CrewAI provider so tools come back as native CrewAI `BaseTool` instances |
| 2 | `composio.create(user_id="zealt-user01", toolkits=["github","slack"])` | Opens a session scoped to GitHub + Slack for the test user |
| 3 | `session.tools()` | Fetches all provider-wrapped tools; then split into `github_tools` / `slack_tools` by name prefix so each agent only sees what it needs |
| 4 | `LLM(model="gpt-4o-mini")` | Single shared LLM using CrewAI's built-in `LLM` class (no extra `langchain_openai` dep) |
| 5–6 | `Agent(...)` | **GitHub Researcher** receives `github_tools`; **Slack Reporter** receives `slack_tools`; both have `allow_delegation=False` to keep routing deterministic |
| 7 | `Task(...)` | `research_task` instructs the researcher to return the last 3 commits with short SHAs; `reporting_task` takes `context=[research_task]` so the reporter automatically receives the researcher's output |
| 8 | `Crew(..., process=Process.sequential)` | Tasks run in order (research → report); `crew.kickoff()` drives execution and the final result is printed |
