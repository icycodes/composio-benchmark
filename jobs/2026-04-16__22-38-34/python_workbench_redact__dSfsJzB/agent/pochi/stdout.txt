1. **Initializes Composio** with `OpenAIProvider` and creates a tool-router session for `zealt-user01` with the GitHub toolkit and Workbench enabled.

2. **Schema Modifier** – The `@schema_modifier(tools=["GITHUB_GET_AN_ORGANIZATION"])` decorator removes the `org` property from the tool's input schema and its `required` list, so the LLM never sees it. The value `"ComposioHQ"` is injected at execution time by the script directly (not by the LLM).

3. **Fetches org info** – Calls `GITHUB_GET_AN_ORGANIZATION` directly with the hardcoded `org="ComposioHQ"`. Retrieved:
   - Organization Name: `Composio`  
   - Public Repositories Count: `70`

4. **Workbench execution** – Uses `COMPOSIO_REMOTE_WORKBENCH` (via `execute_meta`) to run Python code in the remote sandbox that creates the directory and writes the summary file.

5. **Local file written** at `/home/user/workbench-task/org_summary.txt`:
   ```
   Organization Name: Composio
   Public Repositories Count: 70
   ```

**Key implementation details:**
- Meta tools (`COMPOSIO_REMOTE_WORKBENCH`, `COMPOSIO_SEARCH_TOOLS`, etc.) are routed through `execute_meta()` on the session API client.
- App tools (`GITHUB_GET_AN_ORGANIZATION`) go through `session.execute()`.
- The schema modifier uses `@schema_modifier(tools=[TOOL_SLUG])` decorator pattern as provided by the Composio SDK.
